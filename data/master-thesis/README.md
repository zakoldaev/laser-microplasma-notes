# Master’s thesis raw data — placeholder

This folder is reserved for original experimental files connected to the master’s-thesis research story.

Nothing has been added yet.

## Planned subfolders

- `process-window/` — laser power, scan speed, pulse duration, repetition rate, passes
- `profilometry/` — relief-depth traces and surface profiles
- `porous-glass-transmission/` — transmission spectra and long-term aging measurements
- `microscopy/` — optical, polarized-light and scanning-probe microscopy
- `microlens-arrays/` — geometry and optical testing
- `random-phase-plates/` — beam-homogenization measurements
- `diffraction-gratings/` — grating profiles and diffraction measurements
- `parallel-processing/` — titanium-film processing images and related data

## When files are added

For each dataset, record:

1. original filename and date, if known;
2. sample/material;
3. experimental conditions;
4. instrument/software;
5. which thesis figure or publication it relates to;
6. whether the data were published, unpublished, or re-analysed later;
7. any uncertainty about metadata.

Large archival datasets may later be moved to a DOI-bearing repository, with this GitHub folder keeping example files, metadata, analysis scripts, and links.
