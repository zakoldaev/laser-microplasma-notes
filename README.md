# laser-microplasma-notes

Research notes, experimental data and additional material on laser microplasma processing of transparent materials.

This private repository is a working archive for reconstructing experiments behind our published work: practical setup details, selected original data, unsuccessful trials, later interpretation, and links to the peer-reviewed papers.

1. [Laser passivation of porous glass — the starting point](notes/01-laser-passivation-porous-glass.md)
2. [Laser microplasma fabrication of a phase grating](notes/02-phase-grating.md)

## Research trajectory

The archive follows the development of the research approximately as:

porous-glass stabilization → LIBBH / laser-assisted surface modification → controlled glass microstructuring → phase optical elements → laser microplasma processing of glass and crystals → process physics and reproducibility.

## Planned topics

- Laser-induced black-body heating (LIBBH)
- Fast microstructuring of silica glasses
- Random phase plates
- Multilevel phase plates
- Processing of crystalline and birefringent materials
- Focusing conditions and process reproducibility
- Original profilometry and microscopy data
- Practical process windows and failed experiments

## Working principle

The peer-reviewed publications remain the authoritative sources for the original results. Additional material in this repository will be distinguished as published data, original experimental data, laboratory record, personal recollection, or new analysis.
