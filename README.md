# Laser microplasma notes

Research notes on **laser microplasma processing of transparent dielectric materials**, with a focus on porous glass, fused silica, birefringent crystals, and the fabrication of micro-optical surface elements.

This repository follows one experimental line from the first glass–carbon experiments and porous-glass passivation to controlled surface relief and functional micro-optics. It is a research-story archive: the peer-reviewed papers remain the authoritative source for published results, while the notes add chronology, experimental context and retrospective observations from the laboratory.

> [!NOTE]
> **Status:** This is an evolving research archive and also my first attempt to build and maintain a scientific story in GitHub. The core scientific results are tied to the cited publications, while historical context, photographs, presentations, figures and retrospective notes will continue to be added as I recover and review the material. The repository is therefore expected to change and improve over time.

### Terminology used in this archive

The name of the process changed as the work developed. In the 2014–2016 conference abstracts and early papers we commonly used **laser-induced black-body heating (LIBBH)**, reflecting the thermal interpretation of the glass–graphite interaction. From 2017 onward, several papers used **laser-induced microplasma (LIMP)** and examined the plasma-mediated mechanism more directly. Throughout this repository I use **laser microplasma processing** as the common descriptive name for the full research line.

## Rethinking the results

The original experiments gradually moved from surface modification to functional micro-optics. Years later, that leaves a different question:

> **What could the same fabrication platform be useful for now?**

The [**Rethinking the results**](rethinking/README.md) branch starts from demonstrated capabilities and follows them into new problems using current numerical tools and application needs. The aim is not to prescribe one application, but to show how the earlier fabrication ideas can be revisited, redesigned and tested in new contexts. Reproducible simulations are included where useful so other readers can change the assumptions and explore their own directions.

These notes are deliberately forward-looking: they connect the earlier work to possible next experiments without changing the claims of the original papers.
