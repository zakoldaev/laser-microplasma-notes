# Rethinking the results

This section revisits earlier experiments from a present-day perspective. The aim is not to rewrite the published results, but to ask what I would do differently now using the same fabrication platform together with current numerical tools, newer optical applications and a better understanding of the practical limits of the process.

The notes in this folder are therefore exploratory. Published results remain tied to the original papers; simulations and design ideas here are working hypotheses that should be tested experimentally.

## Current ideas

- [From random phase plates to a microfluidic Raman probe](01-raman-microfluidic-flat-top.md) — reuses the demonstrated multilevel fused-silica phase-plate capability for a different problem: reducing trajectory-dependent Raman-signal variation from particles flowing through a confocal probe volume.

## How I want to use this section

For each idea I try to keep the same structure:

1. **Original result** — what was actually demonstrated.
2. **Limitation or open question** — what the earlier experiment did not address.
3. **What I would do now** — a new design or experiment enabled by the same technology.
4. **Why it may matter** — the application or physical question behind it.
5. **What needs to be tested** — what is still simulation, assumption or proposal.

This is intended to be an evolving branch of the archive rather than a retrospective claim that the newer ideas were already part of the original work.
